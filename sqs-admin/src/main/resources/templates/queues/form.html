キュー作成

AWS SQS CreateQueue で指定できる属性をすべて設定できます（ローカル ElasticMQ では未対応の項目がある場合があります）。

基本
英数字・ハイフン・アンダースコア
メッセージ設定
0〜900 秒。全メッセージの配信遅延
1024〜1048576 バイト
60〜1209600 秒（最大14日）
ロングポーリング 0〜20 秒
0〜43200 秒（最大12時間）
FIFO 専用
デッドレターキュー (RedrivePolicy)
ARN を直接指定（ローカルは 000000000000 アカウント）
既存キューから選択（ARN は自動生成）
DLQ 許可 (RedriveAllowPolicy)
byQueue 選択時は必須（最大10件）
サーバーサイド暗号化
SQS マネージド SSE と KMS は同時指定不可
60〜86400 秒（KMS 時）
ポリシー・タグ
空欄の場合は送信しません
1行1タグ、key=value 形式（CreateQueue の tags パラメータ）
